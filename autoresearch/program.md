# autoresearch：优化 primitive 式"用形状画图"

目标：把拟合算法做得更快、更好。固定时间、固定字节预算下，让 SVG 在浏览器里渲染出来尽量像目标图（《千里江山图》画心，5612×240）。
收尾时给新旧算法各跑 10/20/45/90 秒，看新算法多快能追上旧算法的质量。

规则
- 主要改 `solver.py`（算法怎么改都行，形状种类、搜索方法、编码方式都可以动）。`harness.py`、`../target.png`、评分方法都不动。
- 每次实验运行 `python3 harness.py "这次改了什么"`。
- solver 限时 60 秒（12 核），超时算失败。
- solver 输出两份 SVG：gzip -9 后不超过 16,000 字节和 160,000 字节。
- 分数：两份 SVG 用 headless Chrome 按 1:1 渲染，分别和目标图算 SSIM（亮度通道），取平均。
- 护栏：平均 PSNR 比当前最好版本低 0.3 dB 以上的不收，防止只刷 SSIM。
- SVG 只能用矢量图元：不许 `<image>`、`data:`、外部引用、`<script>`、`<foreignObject>`。
- 分数比当前最好高出噪声阈值才保留，否则自动回退到最好版本。每次实验的 solver 都存进 `snapshots/`，记录在 `results.tsv`。
- 结束：跑满约 50 次实验，或连续 12 次没有进步。
- 收尾：在另一张图（之前生成的风格画）上对比 baseline 和最终版，看改进是不是只对这张图有效。
