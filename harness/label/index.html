这是做什么的。Code2Pixel 让 coding agent 只写代码画图。VLM 裁判会对每张图逐条判“是 / 否”。这里收集人的判断，用来算裁判和人的一致率。

逐条细则。每条说法只看图回答：看得出来就选“是”，看不出来或拿不准就选“否”。不用考虑图是怎么做出来的。精确修改题会并排给出原图，说法里的“原来的”指原图。快捷键：1–9 选中第几条，Y / N 判是否，→ / ← 换题。

两张比较。同一道题的两张图，选整体更好的一张：先看是否满足题目，再看画面质量（形状、光影、透视、有没有破绽），最后看好不好看。确实分不出才选“差不多”。快捷键：A 左边，S 差不多，D 右边。

互不可见。每个人的答案只有自己和发起人看得到，请独立判断，不要和别人讨论具体题目。作者（哪个 agent 画的）一律隐去。
