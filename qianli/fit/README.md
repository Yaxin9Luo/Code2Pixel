# 测试 B：给参考图，用纯代码复现《千里江山图》

> 图片文件不在仓库里，结果图见 [报告](../../report/index.html)。

目标图：Wikimedia Commons 全卷扫描（39974×1600，公有领域），裁出画心（x 1880–39290），缩到 5612×240。
所有分数都是用 headless Chrome 打开 SVG、按 1:1 渲染后，和目标图比出来的。

- **三角形 SVG（优化器拟合）**：`fit.py` 一次放一个半透明三角形，颜色按最小二乘直接算出，位置用随机撒点加爬山微调，
  每一步都要和原图比对误差。取前 N 个形状，就是一个 N 行的 SVG 程序。
- **手写 SVG（模型看图目测）**：模型只看带坐标网格的原图截图，所有坐标和颜色都凭目测手写，代码不读原图像素。
  一共改了两轮。

## 文件

- `chart.png`：相似度随字节数变化的曲线；`overview.png`：整卷对比；`detail.png`：桥附近局部放大对比
- `eval/tri_N.svg`：N 个三角形的 SVG 程序，用浏览器打开就能看到画；`eval/tri_N_chrome.png`：Chrome 渲染结果
- `b2_handwritten_v1.svg`、`b2_handwritten_v2.svg`：手写版；`b2_views/`：手写时看的网格截图
- `original.jpg`：下载的原图；`target.png`：目标图

## 复现

```bash
python3 fit.py target.png shapes.json --total 50000   # M2 Pro 12 核约 90 秒
python3 evaluate.py target.png shapes.json eval --ns 10,30,100,300,1000,3000,10000,30000,50999
python3 chrome_check.py target.png b2_handwritten_v1.svg b2_handwritten_v2.svg
python3 plot.py
```

SSIM 是按 Wang et al. 2004 自己实现的（亮度通道，高斯窗 σ=1.5），没有和 scikit-image 对过数。没有算 LPIPS。
